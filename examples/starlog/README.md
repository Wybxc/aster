# Aster Starlog

An Aster port of Astro's Starlog example. It demonstrates a release collection,
full-entry rendering on an index, dynamic detail routes, and responsive
light/dark styling.

```sh
cargo run -- build -p examples/starlog
cargo run -- dev -p examples/starlog
```

The original example and its images are distributed under the license in
`ASTRO-LICENSE`. The upstream Sass has been translated to plain CSS because
Aster publishes CSS directly.
