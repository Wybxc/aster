# Field Notes blog

An editorial Aster example demonstrating content collections, dynamic post
routes, RSS and sitemap generators, local project assets, and semantic article
templates.

```sh
cargo run -- build -p examples/blog
cargo run -- dev -p examples/blog
```

The current copy is original to Aster. Photographs and their CC0 provenance are
listed in [`../IMAGE-CREDITS.md`](../IMAGE-CREDITS.md). A notice covering an
earlier upstream revision is preserved in `UPSTREAM-LICENSE`.
