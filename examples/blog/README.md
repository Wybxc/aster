# Aster Blog

An Aster port of Astro's official Blog example. It demonstrates content
collections, dynamic post routes, RSS and sitemap endpoints, local fonts, and
project-root asset references.

```sh
cargo run -- build -p examples/blog
cargo run -- dev -p examples/blog
```

The original example and its assets are distributed under the license in
`ASTRO-LICENSE`. The global style is derived from Bear Blog's MIT-licensed
default theme, matching the upstream Astro example.
