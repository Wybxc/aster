# Relay release log

A fictional product changelog demonstrating a release collection, full-entry
rendering on an index, dynamic detail routes, and responsive light/dark styling.

```sh
cargo run -- build -p examples/release-log
cargo run -- dev -p examples/release-log
```

Relay and its release notes are fictional. Photographs and their CC0 provenance
are listed in [`../IMAGE-CREDITS.md`](../IMAGE-CREDITS.md). An upstream notice
from an earlier revision is preserved in `UPSTREAM-LICENSE`.
