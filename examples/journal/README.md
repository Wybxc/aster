# Papertrail journal

Papertrail is a feature-rich Aster journal example. It demonstrates content
collections, featured and dated posts, tags, archives, pagination, RSS, a
sitemap, responsive navigation, light/dark themes, and article metadata.

```sh
cargo run -- build -p examples/journal
cargo run -- dev -p examples/journal
```

The current name, copy, favicon, and example identity are original to Aster.
The implementation evolved from an earlier permissively licensed design; its
required notice remains in `UPSTREAM-LICENSE`.
