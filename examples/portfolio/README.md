# Aster portfolio

A fictional product-design portfolio demonstrating nested content IDs, dynamic
project routes, component-owned interaction, responsive layouts, and a
persistent light/dark theme.

```sh
cargo run -- build -p examples/portfolio
cargo run -- dev -p examples/portfolio
```

Mira Chen and the project stories are fictional. Photographs and their CC0
provenance are listed in [`../IMAGE-CREDITS.md`](../IMAGE-CREDITS.md). A notice
covering an earlier upstream revision is preserved in `UPSTREAM-LICENSE`.
